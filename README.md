# Deface Page by Cybrfix

An advanced, interactive cybersecurity-themed webpage in a **single HTML file** - dark hacker style, live visual effects and animated status trackers.

## Live Demo

https://cybrfix.github.io/deface-page-cybrfix/deface_final.html

## Features

- Animated lightning strikes on canvas, with thunder flash and a WebAudio thunder sound
- Perlin-noise mouse trail with rainbow particles
- "SYSTEM HACKED" hero with pulsing logo, scanlines and glow effects
- Live-updating stats cards (files encrypted, data stolen, credentials) that change every few seconds
- Falling hacker phrases across the screen
- Status bar with live indicators (INTRUSION_ACTIVE, ENCRYPTION_ENABLED, EXFILTRATION_RUNNING) and a live clock
- Mock buttons (RECOVER SYSTEM / CALL SUPPORT) that clearly state it is a mock page for education
- Custom scrollbar, fully responsive, no external CSS/JS files

## Tech

- HTML5 + CSS3 animations
- Vanilla JavaScript (Canvas API, WebAudio API)
- Single file: `deface_final.html`

## How to use

1. Download or clone this repo.
2. Open `deface_final.html` in any browser - or upload it to your own test server to see how a defaced site looks.
3. Customise the hacker name (THUND3R), the team line (TEAM DELTA | Cyber 71 | AWS), the stats and the logo image in the file.

## Note

The logo image is loaded from Imgur; replace that link with your own image if you want the page to work fully offline.
